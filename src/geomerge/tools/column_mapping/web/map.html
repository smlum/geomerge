Column matching rules

First-pass suggestions when mapping a raw column to a target field. An exact term only matches a raw column name equal to it; a contains term matches when found anywhere inside the raw name — if more than one target's contains term matches, the longest (most specific) one wins. An exclude term (exact or contains, same two modes) blocks a raw name from ever matching this target, regardless of any other rule.
